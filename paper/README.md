# Papers describing this module

| Folder / file | What it is | Status |
|---|---|---|
| `preprint/` | Full article (LaTeX, about 2,900 words, 1 figure, 2 tables) for the EdArXiv preprint server | Ready to post once the red author notes are completed |
| `paper.md`, `paper.bib`, `figure.png` | Short paper (about 1,000 words) in the format of the Journal of Open Source Education (JOSE) | For a future JOSE submission; build it with the manual "draft paper PDF" workflow |

Build the preprint with `pdflatex`, `bibtex`, `pdflatex`, `pdflatex` in `preprint/`
(or upload the folder to Overleaf). Text printed in red (`\authornote{...}`) must be
completed by the author before posting.
