# Contributing

Thank you for using or improving these labs. Contributions from teachers and students are
especially welcome.

## Report a problem

Open an [issue](https://github.com/rakesh-sengupta/neural-signalling-labs/issues/new/choose)
and choose **Something is broken**. Say which lab and part, what happened, and which device
and browser you used. A screenshot helps.

## Share how you taught with it

Choose **Teaching with the labs**. Tell us your course, what worked and what students found
hard. Reports like these are the most useful contribution of all.

## Get help

Ask in an issue; there are no silly questions. For anything you would rather not post in
public (for example, the quiz answer key, which is shared with instructors on request), email
rakesh.sengupta@krea.edu.in.

## Change something

1. Fork the repository and create a branch.
2. Make your change. Each lab is one self-contained file, `labs/<lab>/index.html`.
3. Run the tests (see the README); add a check to `tests/run_all.py` if you change what a
   lab reports.
4. Open a pull request describing what you changed and why.

Please keep to the principles the labs were built on:

- **Plain language** for psychology students: short sentences, one idea per screen, no
  unexplained jargon.
- **Fact-checked content.** Cite a source for any new number or claim, and keep the
  booklets, slides and `docs/models.md` consistent with the labs.
- **Say where a model simplifies**, in the lab and in `docs/models.md`.
- **Accessibility:** keyboard access, phone-width layouts, both colour themes, reduced
  motion, no information carried by colour alone, no sound unless the user turns it on.
- **Privacy:** labs must not store or send anything about the user.
